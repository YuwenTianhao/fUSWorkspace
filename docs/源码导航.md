# 源码导航

## 一眼判断该看哪个文件

| 文件 | 单一职责 | 什么时候修改 |
|---|---|---|
| `app/fUSWorkspaceAppV2.m` | App状态、回调和工作流调度 | 增加操作流程、保存内容或连接新算法 |
| `app/fUSWorkspaceLayout.m` | 创建窗口和控件 | 调整界面、按钮、默认控件值 |
| `app/fUSWorkspaceProject.m` | 实验共用配置与截面状态 | 调整参数的共用范围、结果根目录 |
| `app/fUSWorkspaceProjectWorkflow.m` | 项目操作流程 | 调整自动恢复、截面切换、批处理和ROI曲线导出 |
| `app/fUSWorkspaceComparisonWorkflow.m` | 同步截面对照、ROI总览 | 调整跨截面曲线和汇报来源 |
| `app/fUSWorkspaceExportPreview.m` | 内存视频帧预览与确认 | 调整逐帧预览、布局占比和输出尺寸选项 |
| `core/+fus/ExperimentStore.m` | 目录扫描、文件签名与项目保存 | 调整截面发现、相对路径和备份规则 |
| `core/+fus/ImageSequence.m` | 查找、排序、读取和缓存图像 | 支持新文件格式或命名规则 |
| `core/+fus/PDISequence.m` | 校验并读取Marsonics PDI线性数据 | 调整PDI格式或显示重建 |
| `core/+fus/CBVEngine.m` | baseline、信号转换和CBV公式 | 修改现有数值算法 |
| `core/+fus/ExperimentPlan.m` | 实验阶段数据和时间匹配 | 修改默认计划或阶段边界语义 |
| `core/+fus/FrameRenderer.m` | 原图着色、CBV叠加和导出帧 | 修改色表、阈值、透明度或时间戳 |
| `core/+fus/ReportRenderer.m` | 科研汇报画布 | 调整图像/曲线排版、阶段标记和当前亮点 |
| `tests/testCoreAlgorithms.m` | 核心行为的回归保护 | 每次修改算法时 |

## 运行时数据流

```text
SVD文件夹
  → fus.ImageSequence（BMP/PNG）或 fus.PDISequence（PDI）
  → 已排序图像与24帧读取缓存
  → fus.CBVEngine.computeBaseline
  → baseline.Gray / Signal / AnalysisMask
  → fus.CBVEngine.calculateMap
  → 二维CBVMap
  → fus.FrameRenderer
  → 交互叠加图或MP4帧
```

App控制器只负责从控件收集参数并调用这些入口，不再实现图像排序、信号换算或CBV公式。

## 参数边界

`fUSWorkspaceAppV2.cbvParameters` 是界面与数值算法之间唯一的转换点。它生成：

- `SpatialAveragePixels`
- `TemporalAverageFrames`
- `ConversionMode`
- `DynamicRangeDb`
- `Log10PerGray`
- `MinimumBaselineGray`

`displayParameters` 则只包含低阈值、显示范围、透明度、背景和掩膜开关。它们不改变保存的CBV数值。

手绘显示区域按截面保存，只限制彩色活动叠加，不改变定量ROI。显示类型由顶部切换独立控制，选择侧栏页签不会改变图像类型。

## 时间定义

```text
frameTime = 图像序号 / ActualFPS
```

baseline时间范围通过 `fus.CBVEngine.secondsToIndices` 转成图像序号。播放和视频帧率只改变观看速度，不改变实验时间。

## 保存与导出

- 当前CBV结果：保存 `.mat` 数值和 `.png` 显示图。
- 实验项目：自动保存共用参数、实验计划与每个截面的当前帧、ROI、标记、baseline和曲线；使用相对路径与原子保存，保留上一次备份。
- 全实验批处理：按同一设置处理各截面；按截面和批次分别保存分析与可选视频，并输出CSV汇总。
- 视频：每张源图重新计算或渲染；有效画面保持指定比例，再补边到16像素编码边界，避免外部播放器逐行错位；同时保存同名 `_settings.mat`。
- 交互导出先预览，再选择路径；预览和实际汇报视频都使用 `fus.ReportRenderer`。布局位置、曲线占比和报告尺寸按实验保存；批量导出复用设置。预览不调用视频编码器。
- 实验计划和标记：保存UTF-8 CSV。

更具体的扩展步骤见 `docs/如何添加新算法.md`。
