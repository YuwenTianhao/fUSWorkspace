# fUS Workspace 仓库与跨平台配置代码审查

审查日期：2026-10-14。范围：首次纳入版本管理的文件、Windows / macOS CI、版本管理、打包入口，以及 App 启动、图标资源路径、PDI 字节序和既有自动测试的跨平台使用方式。

## 已修复的问题

### P1：Intel Mac 与 R2026a 的测试组合无法运行

原工作流把 Windows、Apple Silicon Mac、Intel Mac 与 R2025a / R2026a 做笛卡尔积，生成了 Intel Mac / R2026a 任务。MathWorks 从 R2026a 起不再提供 Intel Mac 版本，该任务会在安装 MATLAB 时失败，最终汇总检查永远无法通过。

修复：改为明确列出六个有效组合，Intel 使用 R2025a / R2025b，其余平台使用 R2025a / R2026a。同步修正 README 与双平台开发指南的 Intel 版本上限。

证据：https://www.mathworks.com/support/requirements/apple-silicon.html

## 审查结论与待验证事项

本次范围内未发现剩余的确定性阻断缺陷。修复后的文件可提交到审查分支。此结论不是 Mac 实测通过的声明。

GitHub 私有仓库已连接，源码已上传到 setup/cross-platform-review，草稿 PR：https://github.com/YuwenTianhao/fUSWorkspace/pull/1 。

首轮 CI 的 Check CI license configuration 已执行，失败原因明确为仓库尚未配置 MLM_LICENSE_TOKEN。MATLAB 矩阵任务因此跳过，汇总检查失败；这不是算法测试失败的证据。私有仓库必须配置该令牌后才能运行云端 MATLAB 检查。六个矩阵任务应在实际 GitHub 执行环境中全部通过，才能认定对应组合通过自动检查。

图标在 Apps 工具栏中的实际显示、窗口布局、ROI 交互、播放流畅度以及真实实验数据的使用体验，需要在实体 Mac / Windows 上验收。CI 检查 Icon 属性已设置，不能证明 MATLAB Gallery 实际显示了图标。
