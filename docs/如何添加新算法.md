# 如何添加新算法

## 先判断算法属于哪一层

| 你想修改的内容 | 应该进入哪里 |
|---|---|
| 图像文件识别、排序、读取或缓存 | `core/+fus/ImageSequence.m` |
| PDI头部校验、线性数值读取或显示重建 | `core/+fus/PDISequence.m` |
| baseline、滤波、信号转换或 CBV 数值公式 | `core/+fus/CBVEngine.m` |
| 实验阶段表和时间匹配 | `core/+fus/ExperimentPlan.m` |
| 色表、阈值、透明度、背景或导出画面 | `core/+fus/FrameRenderer.m` |
| 按钮、窗口和控件排版 | `app/fUSWorkspaceLayout.m` |
| 控件值如何交给算法、保存和导出流程 | `app/fUSWorkspaceAppV2.m` |

## 修改现有 CBV 算法

数值计算只有两个公开入口：

```matlab
baseline = fus.CBVEngine.computeBaseline(sequence, timeRange, actualFPS, parameters);
[map, indices] = fus.CBVEngine.calculateMap(sequence, baseline, centerIndex, parameters);
```

`computeBaseline` 负责生成 baseline 结构，`calculateMap` 负责生成某个时间点的二维数值图。App 不再自己实现这两套公式。

如果新算法需要参数：

1. 在 `CBVEngine.defaultParameters` 和 `validateParameters` 中定义其含义；
2. 在 `fUSWorkspaceLayout` 的 CBV 页增加控件；
3. 在 `fUSWorkspaceAppV2.cbvParameters` 中把控件值转换成算法参数；
4. 在 `collectConfiguration` 和 `applyConfiguration` 中同步保存与恢复；
5. 在 `tests/testCoreAlgorithms.m` 增加一个可以手算结果的测试。

## 增加并行的新算法

如果新方法与当前相对 CBV 公式差异很大，不要继续扩大 `CBVEngine`。在 `core/+fus` 下新建语义明确的类，例如：

```text
core/+fus/ActivationDetector.m
core/+fus/FunctionalConnectivity.m
core/+fus/MotionCorrection.m
```

每个算法类应做到：输入和输出明确、不读取界面控件、不创建窗口、能够用合成数据测试。随后只在 App 控制器中增加很薄的一层调用。

## 修改后的检查

在 MATLAB 中运行：

```matlab
run("tests/run_all_tests.m")
```

测试会检查代码语法、图像排序、baseline映射、未知log差值、线性功率百分比、实验阶段边界、渲染掩膜，以及 App 窗口能否正常创建。
